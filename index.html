Google Scholar has no public data API, so it cannot be synced directly. Export your papers from Scholar as BibTeX and import them below. Citation counts and citing papers come from OpenAlex, which indexes ORCID-linked works. Scholar's own counts can differ.

Import from BibTeX

Paste the contents of a .bib file, for example from Google Scholar, a publisher or a reference manager. Entries already in the list (same title) are skipped.

Backup

Your data stays in this browser (localStorage). Nothing is uploaded. Sync sends only your ORCID iD or OpenAlex ID and name to OpenAlex, a free, open scholarly index. Export a JSON backup before clearing browser data.
